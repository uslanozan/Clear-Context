# Brand assets

Original to this project:

- `clear-context-logo.webp`: the main logo, a document broken into six glass pieces. Generated with Muse Image 1.0 (Meta), two pieces moved outward by hand, background recolored to the app gray.
- `clear-context-mark.png`: the small mark, a broken glass C, generated with Muse Image 1.0 and cleaned by hand. Favicons and extension icons are exported from it.
- `backdrop.webp`: the main logo blurred, used behind glass surfaces.

These images are AI-generated illustrations, not photographs.

Third-party, not covered by the application license:

- `meta.svg`: official Meta wordmark from https://dev.meta.ai/logo/meta-logo-with-text.svg
- `muse-logo.svg`: official Muse logo from https://muse.ai/images/landing/brand/muse-logo.svg.

The official Jolly image is not included while a permission request to Meta is pending.
