# PDF fonts

Static TrueType instances used only by the PDF export, because the app's web fonts are split by
script and the PDF renderer needs one file per weight with the full character set (including
Turkish letters).

| File                                                | Family         | Source       | License                                  |
| --------------------------------------------------- | -------------- | ------------ | ---------------------------------------- |
| `FunnelSans-Regular.ttf`, `FunnelSans-SemiBold.ttf` | Funnel Sans    | Google Fonts | SIL OFL 1.1, see `OFL-funnelsans.txt`    |
| `FunnelDisplay-SemiBold.ttf`                        | Funnel Display | Google Fonts | SIL OFL 1.1, see `OFL-funneldisplay.txt` |
| `JetBrainsMono-Regular.ttf`                         | JetBrains Mono | Google Fonts | SIL OFL 1.1, see `OFL-jetbrainsmono.txt` |

The files are unmodified.
